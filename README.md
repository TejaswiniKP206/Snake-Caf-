# 🐍 Snake Café

A cozy, themed Snake game built with **Python and Pygame**. Collect food, grow your snake, beat your high score, and explore four colorful environments!

## 🎮 About the Project

Snake Café is a desktop arcade game created as a Python programming project. It combines classic Snake gameplay with a cozy café-inspired design and theme changes as your score increases.

## ✨ Features

- 🎨 **Four themes:** Café, Jungle, Ocean, and Desert
- 🐍 Snake colors that match each environment
- 👀 Two directional eyes on the snake's head
- 🍪 Theme-specific collectibles
- 🏆 Score tracking and saved best score
- 📈 Level progression every 50 points
- ⚡ Increasing game speed as your score grows
- ⏸️ Pause, resume, and restart controls

## 🛠️ Built With

- Python
- Pygame

## 🚀 Getting Started

### Prerequisites

Install Python 3 and pip on your computer.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/snake-cafe.git
   ```

2. Open the project folder:

   ```bash
   cd snake-cafe
   ```

3. Install Pygame:

   ```bash
   python -m pip install pygame
   ```

4. Run the game:

   ```bash
   python game.py
   ```

## 🎯 Controls

| Key | Action |
|---|---|
| Arrow keys / WASD | Move the snake |
| Space | Pause or resume |
| R | Restart the game |
| Esc | Quit |

You can also use the on-screen Start, Pause, and Reset buttons.

## 🌍 Game Themes

| Level | Theme | Collectible |
|---|---|---|
| 1 | ☕ Snake Café | Cookie |
| 2 | 🌿 Jungle Escape | Berries |
| 3 | 🌊 Ocean Quest | Pearl |
| 4 | 🏜️ Desert Adventure | Cactus fruit |

A new theme is unlocked as your score reaches the next 50-point milestone.
